This directory contains input data files for this analysis/paper

These include:

#### Genbank files with with reptarenavirus sequences 

- all_reptarenavirus_L_seqs_2025_10_31.gb: all reptarenavirus L segment sequences from the NCBI nucleotide database on Oct 31, 2025
- all_reptarenavirus_S_seqs_2025_10_31.gb: all reptarenavirus S segment sequences from the NCBI nucleotide database on Oct 31, 2025

#### Genbank files subsetted to include coding-complete sequences

- coding_complete_L_for_trees.gb: the coding-complete L segment sequences included in trees
- coding_complete_S_for_trees.gb: the coding-complete S segment sequences included in trees

#### Coding-complete coding sequences (CDS) from the above files

- GP_CDS.fasta
- L_CDS.fasta
- NP_CDS.fasta
- Z_CDS.fasta

#### Protein sequences (from corresponding cds)

- GP_prot.fasta
- L_prot.fasta
- NP_prot.fasta
- Z_prot.fasta

#### L and NP protein sequences including LCMV sequences as an outgroup for rooting

- L_incl_LCMV_prot.fasta
- NP_incl_LCMV_prot.fasta

#### ICTV Master Species List 

- ICTV_Master_Species_List_2025_MSL41.v1.xlsx: The ICTV master species list file, MSL41.v1, [downloaded from the ICTV website](https://ictv.global/msl)

#### Metadata related to snakes from Hepojoki et al (2015), Table 1

- Hepojoki_2015_table_1.xlsx
